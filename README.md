# 🩺 AyuSynk Frontend Clone

AyuSynk Frontend Clone is a responsive healthcare web application UI built using **HTML, CSS, and JavaScript**.
This project replicates the design and user experience of a modern healthcare platform like AyuSynk.

---

## 🚀 Features

* 🎨 **Modern UI Design**

  * Clean and user-friendly interface
  * Healthcare-themed layout

* 📱 **Fully Responsive**

  * Works on mobile, tablet, and desktop

* 🧑‍⚕️ **Doctor Section**

  * Doctor profiles
  * Specializations display

* 📅 **Appointment UI**

  * Booking interface (UI only)
  * Interactive elements using JavaScript

* 🧭 **Navigation System**

  * Smooth scrolling
  * Multi-section landing page

* ⚡ **Interactive Components**

  * Buttons, forms, modals
  * Basic DOM manipulation

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsiveness
* **JavaScript (Vanilla JS)** – Interactivity
